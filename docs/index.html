Learning control for a wastewater plant: reproduction and extension

This site has two parts. Part 1 re-implements the base paper, Wang, Li, Ren and Qiao, “Multiagent Adaptive Critic Control With Expert Knowledge for Wastewater Treatment Plants”, IEEE Transactions on Industrial Informatics, 2026 (DOI 10.1109/TII.2026.3659924). Part 2 adds machine learning that predicts what the plant is about to face. Every chart is drawn from simulations run with the repository code, and nothing is hand-drawn.

1 · The base paper, reproduced →

The BSM1 plant, the PID expert prior, and the multi-agent adaptive critic (MAACC): one agent per control loop, a coupling-aware cost and online actor-critic learning. Includes an animated plant, the control law broken into its parts, and the critic-update flaw found in eq. (15).

2 · The ML extension →

A probabilistic influent forecaster, a neural digital twin, the PANDA controller u = b + g·a + f, and an early warning of effluent-ammonium violations, each evaluated on data it never saw and compared with simple baselines.

Verification ledger

Each claim made in this project, its status and the evidence for it. Verified means a test or held-out experiment confirms it. Partial means it holds with a caveat stated next to it. Not verified / not done means exactly that.

Reproduce everything

pip install -r requirements.txt
python -m pytest tests -v                          # 34 tests, ~7 min
python experiments/01_train_forecaster.py          # influent forecaster (~10 min)
python experiments/02_train_twin.py                # digital twin (~40 min)
python experiments/04_collect_warning_data.py      # early-warning corpus (~15 min)
python experiments/05_warning_benchmark.py         # early warning: train + evaluate
python experiments/06_export_site_data.py          # every simulation behind this site
python experiments/07_build_site_data.py           # pack results into docs/data/site-data.js
Source: github.com/Amritha902/water_resource. Simulator caveat: BSM1 is re-implemented from its published definition, and the influent files are statistically equivalent rather than the official ones. Absolute numbers therefore differ from the paper's Table II. All comparisons on this site are between controllers run on the same simulator.
