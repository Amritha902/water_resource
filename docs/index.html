Learning control of a wastewater plant: two papers, reproduced and extended

A BSM1 wastewater plant built from scratch. Two published learning controllers are re-implemented on it, and each is extended with models that predict what the plant is about to face. Every chart on this site is drawn from simulations run with the repository code, and every claim is listed below with its evidence, including the ones that failed.

Paper 1 · MAACC →

Wang, Li, Ren, Qiao, IEEE TII 2026. One adaptive-critic agent per loop (air → oxygen, recycle → nitrate), a learned correction on top of an expert PID, and a cost that charges each agent for both loops. The page has an animated plant, the control law broken into its parts, results and every deviation.

Paper 2 · DDPG aeration →

Du, Chen, Han, Qiao, Sci China Tech Sci 2023. Drop the DO set point and let a DDPG agent trade aeration energy against effluent quality. The page shows the physics, a replay of the evaluation week, the reproduction, the hidden violation cost, and PANDA-RL.

Prediction models →

The influent forecaster, the neural digital twin and the effluent-ammonium early warning that both extensions build on. Each is re-checked on data it never saw, against a simple baseline.

Verification ledger

Verified means a test or held-out experiment confirms the claim. Partial means it holds with the caveat given next to it. Not verified / failed / not done means exactly that. Numbers are read from the result files when the page loads.

Reproduce everything

pip install -r requirements.txt
python -m pytest tests -v                              # the test suite
python experiments/03_run_control.py --seeds 2         # paper 1: 54-run tracking benchmark
python experiments/06_aeration_benchmark.py            # paper 2: aeration benchmark
python experiments/11_budget_frontier.py               # PANDA-RL: energy / violation frontier
python experiments/12_weight_sweep.py                  # PANDA-RL: network changes isolated
python experiments/10_dyna_ablation.py                 # PANDA-RL: Dyna ablation
python experiments/04_collect_warning_data.py          # early warning: corpus
python experiments/05_warning_benchmark.py             # early warning: evaluation
python experiments/09_write_results.py                 # regenerate docs/05_results.md
# this website
python experiments/13_export_site_data.py --stages critic twin forecaster closed_loop fig4
python experiments/16_replay_paper2.py DDPG-B          # (also PID, PANDA-RL)
python experiments/15_export_warning_extras.py
python experiments/14_build_site_data.py               # writes docs/data/site-data.js
