# Paper draft (LaTeX, IEEEtran)

`main.tex`, `refs.bib` and `figures/` form an Overleaf project.

* Upload the folder (or the zip) to Overleaf: New Project → Upload Project.
* Compiler: pdfLaTeX. Main document: `main.tex`.
* Compile with pdfLaTeX; `main.pdf` is the compiled version.

  * acknowledgment;
  * the AI-assistance disclosure your venue asks for.
* Every number in the text and tables comes from the audited result files
  (`results/paper1_final_figure_table.json`, `results/paper1_audit.json`).
* Figures:
  * `d*.png`: the draw.io diagrams in `docs/diagrams/`, without titles;
